# HurtowniaWebApp
PL:
System informatyczny wspierający hurtownie w formie aplikacji webowej z dedykowanym API. System wykorzystuje architekturę klient-serwer. Stworzony w ramach pracy dyplomowej w 2023r. w ramach studiów na Warszawskiej Wyższej Szkole Informatyki.
Najważniejsze wykorzystane technologie to: ASP.NET Core 6.0, Entity Framework Core, ASP.NET Core JwtBearer, ASP.NET Core Identity, ASP.NET Core Session, Newtonsoft Json.NET, DinkToPdf.
Repozytorium zawiera również testy automatyczne aplikacji. Testy back-endu wykorzystują MSTest, a front-endu - Selenium WebDriver.

ENG:
IT system supporting warehouse/wholesale stores in the form of a web app with a dedicated API. The system uses the client-server architecture. Created for the engineering degree defense in 2023 as part of studying at the Warsaw School of Computer Science.
Most important of the used technologies: ASP.NET Core 6.0, Entity Framework Core, ASP.NET Core JwtBearer, ASP.NET Core Identity, ASP.NET Core Session, Newtonsoft Json.NET, DinkToPdf.
The repository also contains automated tests for the app. The backend tests use MSTest and the frontend ones use Selenium WebDriver.
